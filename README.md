### Cybersecurity • Penetration Testing • Security Engineering • IT

Welcome to **CyberWithSandiso (CWS)** — a cybersecurity-focused portfolio, learning platform, laboratory environment, and knowledge hub built by **Sandiso Mayekiso**.

CyberWithSandiso was created to document and demonstrate practical cybersecurity knowledge while building a structured environment for continuous learning.

The project combines:

- 🖥️ Network security
- 🐧 Linux and Windows security
- 🧪 Controlled security laboratories
- 📚 Technical documentation
- 🎓 CWS Academy
- 📊 Student progress tracking
- 🏆 Assessments and certificates
- 💻 Software development
- 🔎 Security research

The long-term goal is to develop CyberWithSandiso into a complete cybersecurity learning and practical training platform.

🏆 Certificates

The CWS Academy includes a certificate system designed around course completion.

Certificate eligibility will be tied to requirements such as:

Required lessons completed
Required practical work completed
Required assessments passed
Course completion requirements satisfied

The long-term objective is to provide certificate verification so that certificates issued by CWS can be validated independently.

🔒 Security & Responsible Use

CyberWithSandiso is intended for education, research, and authorized security testing.

Security techniques demonstrated through the project should only be applied to:

Systems you own
Dedicated training environments
Intentionally vulnerable applications
CTF environments
Systems where explicit authorization has been granted

Do not use the material to access, disrupt, or test systems without permission.
